# AI Usage Disclosure

## AI Tools Used

1. **ChatGPT (OpenAI)** was used as a development and learning assistant throughout this project. The work was completed through a combination of AI-assisted coding and my own implementation, problem-solving, testing, and experimentation.

## Part-by-Part Disclosure (ChatGPT)

| Part | AI assistance category |
|---|---|
| Part A - Tokenizer | Code generation |
| Part B - GPT Model | Code review |
| Part C - Training | Debugging |
| Part D - Text Generation | Concepts |
| Part E - Experiments | Concepts |
| Part F - Report | Code review |

### Part A - Tokenizer
ChatGPT helped explain the byte-level BPE algorithm and assisted with some implementation details. I worked on integrating the tokenizer, running the training process, testing encoding and decoding, and checking the merge results.

### Part B - GPT Model
ChatGPT provided explanations of the Transformer architecture and reviewed parts of the model implementation. I worked on assembling the model components, understanding their interactions, testing tensor shapes, and verifying the parameter count and loss calculation.

### Part C - Training
ChatGPT helped identify and troubleshoot training-related problems. I configured the experiments, worked with the learning-rate schedule and optimizer settings, executed training runs, and monitored the training and holdout-shard losses.

### Part D - Text Generation
ChatGPT explained sampling methods and KV caching. I worked with the generation implementation, executed the tests, compared cached and non-cached outputs, and measured generation performance.

### Part E - Experiments
ChatGPT helped explain experimental design and compare possible outcomes. I selected experiment configurations, ran the S, M, L and ablation experiments, collected the results, maintained `runs.csv`, and created and reviewed the figures.

### Part F - Report
ChatGPT reviewed the report structure and helped interpret technical results. I selected the evidence, checked the numerical values against my logs, examined the generated samples, and finalized the report content.

## Personal Contribution
I was actively involved in all stages of the project. I implemented and modified code, made technical decisions, configured and executed experiments, investigated errors, tested model behavior, and evaluated the results. The AI tools provided assistance with explanations, selected code implementations, debugging, and reviewing, while I remained responsible for running, checking, and understanding the project.
